Slot Symbols Guide

A slot symbol is an icon or value defined by a game’s paytable. Some symbols form ordinary winning combinations, while special symbols can substitute, trigger features, carry prize values or modify wins.
Important: Similar feature names can use different trigger rules and mathematics. The exact game information screen and paytable remain the final reference.

How to read symbols in a slot

1

Open the paytable or information screen

This is the primary reference for symbol values and special behaviour.

2

Identify regular pay symbols

These usually form standard winning combinations under paylines, ways or cluster rules.

3

Identify special symbols

Look for Wild, Scatter, Bonus, Money, multiplier or feature-specific icons.

4

Check where each symbol can land

Some symbols appear only on particular reels or only during bonus play.

5

Check interaction rules

Confirm whether a Wild substitutes for a symbol, whether a Scatter pays, and how Bonus or Money symbols are evaluated.

Main types of slot symbols

A

Regular pay symbol

Forms normal winning combinations and usually has a value listed in the paytable.

W

Wild

Usually substitutes for selected regular symbols.

S

Scatter

Often pays or triggers a feature based on count rather than a normal payline.

B

Bonus symbol

Can activate a separate bonus feature when the stated condition is met.

$

Money / Cash symbol

Carries a prize value or multiplier and is often used in hold-and-respin features.

×

Multiplier symbol

Applies a stated multiplier to an eligible win or feature total.

?

Mystery symbol

Transforms or reveals another symbol/value under the game rules.

C

Collect symbol

Collects values from other symbols or positions during a feature.

Frequently asked questions

Are all symbols worth the same amount?

No. Regular symbols can have different paytable values, and special symbols may work through feature rules instead of ordinary payouts.

Does every slot have a Wild and Scatter?

No. These are common features, but games can use different symbol sets.

Can a Wild replace a Scatter?

Usually not unless the paytable specifically allows it.

What is the best place to confirm a symbol’s exact role?

Use the game’s own paytable or information screen because symbol behaviour is title-specific.
