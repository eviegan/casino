Progressive Jackpot Explained

A progressive jackpot is a jackpot whose displayed value grows according to the system's contribution rules until the prize is triggered and awarded.
Important: Similar feature names can use different mathematics and trigger rules. The exact game information screen should always be treated as the final reference.

Common types & variations

L

Local Progressive

A jackpot linked to one game or a limited operator environment.

N

Network Progressive

A jackpot connected across a wider group of participating games or operators.

Seed

Seed Value

The jackpot resets to a predefined starting amount after a win.

%

Contribution

A defined portion of qualifying bets can be allocated to the current or future jackpot pool.

Meter

Displayed Meter

The current jackpot value is shown in or around the game interface.

Trigger

Trigger Rule

The jackpot can be awarded through a specific bonus, grid-fill condition, random event or other rule.

Frequently asked questions

What is a progressive jackpot?

It is a jackpot prize that can grow over time according to contribution rules until it is won.

What is a jackpot seed value?

It is the predefined amount to which the progressive jackpot resets after a win.

What is the difference between local and network progressive jackpots?

A local jackpot is linked to a smaller game or operator environment, while a network jackpot can pool qualifying activity across a wider network.

Does a high jackpot meter mean it is more likely to hit?

No. The displayed amount reflects prize value, not that the jackpot is due.

Can part of each bet contribute to the next jackpot too?

Yes. Some systems reserve part of contributions for the future reset pool as well as the current jackpot.
